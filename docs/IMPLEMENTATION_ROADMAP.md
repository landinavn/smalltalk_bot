# Small Talk — план разработки

Порядок работ предварительный. После аудита Codex должен уточнить зависимости, риски и последовательность.

## Этап 1. Аудит и безопасность

- Изучить backend и frontend.
- Зафиксировать существующие API и структуру базы.
- Проверить обработку ошибок и безопасность.
- Определить, какие функции уже работают.
- Составить карту технического долга.
- Не менять production.

Результат: подтверждённая техническая картина проекта.

## Этап 2. Архитектура и API

- Утвердить общую модель пользователя.
- Спроектировать платформенные адаптеры MAX и Telegram.
- Определить единый API для frontend.
- Спроектировать безопасную привязку аккаунтов.
- Спроектировать схему уроков, прогресса и подписок.

Результат: согласованная архитектура без дублирования логики.

## Этап 3. Основа frontend

- Убрать стартовый шаблон Vite.
- Создать визуальную систему Small Talk.
- Реализовать адаптивные экраны.
- Подключить авторизацию через платформенные SDK.
- Подключить API после согласования контрактов.

Результат: работающий интерфейс приложения.

## Этап 4. Обучение

- Онбординг.
- Определение уровня CEFR.
- Выбор преподавателя.
- Каталог тем по уровням.
- Управление уроком.
- Исправление ошибок и сохранение словаря.

Результат: полноценная логика обучения.

## Этап 5. Голосовое общение

- Приём аудио от Telegram и MAX.
- Распознавание речи.
- Контекстный ответ AI.
- Английская озвучка.
- Отправка аудио.
- Обработка ошибок и повторных запросов.

Результат: проверенный голосовой диалог end-to-end.

## Этап 6. 3D-преподаватель

- Подбор или создание Digital Human.
- Проверка GLB и лицевого рига.
- Интеграция с Three.js.
- Естественные движения и мимика.
- Lip sync по visemes/phonemes.
- Оптимизация для мобильных устройств.

Результат: постоянно присутствующий анимированный преподаватель.

## Этап 7. Личный кабинет и прогресс

- История занятий.
- Уровень и прогресс.
- Словарь.
- Список ошибок и рекомендации.
- Настройки профиля.

Результат: единая история обучения на обеих платформах.

## Этап 8. Подписки и платежи

- Бесплатный тест.
- Один бесплатный урок 15 минут на пользователя.
- Подписки на 1 неделю, 1, 3, 6 и 12 месяцев.
- Учёт лимитов.
- Защита от повторного списания.
- Платёжные интеграции после проверки правил платформ.

Результат: готовая коммерческая модель.

## Этап 9. Тестирование и запуск

- Unit и integration tests.
- Проверка Telegram и MAX.
- Проверка мобильных устройств.
- Нагрузочные тесты.
- Проверка безопасности.
- Поэтапный выпуск.

Любые production-релизы — только после отдельного разрешения пользователя.
